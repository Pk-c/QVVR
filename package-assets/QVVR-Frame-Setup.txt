QVVR - Steam Frame USB manager (Windows PC)
==========================================

1. Close QV yourself on the Frame. Connect Frame to this PC over USB.
2. Enable Frame Developer Mode / USB debugging and authorize the PC in the headset.
3. Extract QVVR-Frame-Setup.zip beside QVVR-vX.Y.Z.zip (do not unpack the mod ZIP).
4. Put official Android SDK Platform Tools in the same folder, so the path is
   platform-tools/adb.exe. An existing adb on PATH or Android SDK is also accepted.
   In the developer checkout the existing ignored .deps ADB is detected too.
5. Double-click QVVR-Frame-Setup.bat. Select Install/update or Uninstall.

No administrator rights, game launch, game termination or permanent PowerShell
execution-policy change is requested. -ExecutionPolicy Bypass applies only to
this script process. Only use a package and scripts from a source you trust.

Installation validates the mod ZIP inventory, metadata and SHA-256 file hashes,
then rechecks hashes on Frame and verifies the installed files. These are
integrity checks, not a digital signature. A .sha256 ZIP sidecar is checked if
present. Unknown ZIP entries, linked content and incompatible shared loader
files are rejected. Close QV before every install, update or uninstall.

Existing QVVR settings and other mods are kept. Differing shared BepInEx/Doorstop
files are NEVER overwritten automatically: review an existing loader manually.
QV.exe and QV_Data are never copied, patched or removed.

Frame Steam launch options must be set manually after the first install:
  WINEDLLOVERRIDES="winhttp=n,b" %command% -force-d3d11
The tool deliberately does not edit Steam configuration or start QV.

Uninstall moves only BepInEx/plugins/QVVR into a recoverable backup. Settings
remain by default; the menu also offers removal of QVVR settings with backup.
Shared BepInEx, winhttp.dll, doorstop_config.ini and other mods remain installed.
You can remove QVVR-specific Steam launch options manually afterwards.

Backups: <Frame game>/.qvvr-backups/<action>-<unique session>/
To restore an uninstall: close QV, copy backup contents into the game folder.
Install backups contain previous overwritten files, installed-files.txt and
new-files.txt (newly added files only; preserved settings are excluded).
When recovering an install manually, restore old files and review newly added
overlay files listed there; never delete the game or the whole BepInEx tree.
Interrupted operations may need this recovery. USB transfer/staging files are
separate from backups; small diagnostic sessions are retained under /tmp.

PowerShell examples (no admin required):
  powershell -NoProfile -ExecutionPolicy Bypass -File .\QVVR-Frame-Setup.ps1 -Action Install -PackagePath .\QVVR-v0.1.0.zip
  powershell -NoProfile -ExecutionPolicy Bypass -File .\QVVR-Frame-Setup.ps1 -Action Uninstall
  powershell -NoProfile -ExecutionPolicy Bypass -File .\QVVR-Frame-Setup.ps1 -Action Uninstall -RemoveConfig

Optional parameters:
  -AdbPath "C:\Tools\platform-tools\adb.exe"
  -Serial <device-serial>        Required if more than one ADB device is connected.
  -RemoteGameDir <absolute-path> Steam storage below /home/steamos or /run/media.
  -WhatIf                       Validate package/device without uploading/modifying.

Default game path:
  /home/steamos/.local/share/Steam/steamapps/common/QV
Both Windows PowerShell 5.1 and PowerShell 7 are supported. This tool is for
Frame USB management; use uninstall.bat beside QV.exe for local PC removal.
